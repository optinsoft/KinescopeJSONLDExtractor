# 🎬 Kinescope JSON-LD Extractor PRO

Браузерное расширение (Chrome Extension) на платформе Manifest V3, предназначенное для автоматического перехвата, очистки и сохранения метаданных, а также прямых ссылок на аудио- и видеопотоки из встроенных плееров Kinescope.

## ✨ Основные возможности

* Пробитие изоляции iframe: Гарантированно внедряется во внутреннюю структуру плеера Kinescope, даже если он загружен со стороннего домена или защищен политиками безопасности.
* Сбор метаданных (JSON-LD): Автоматически извлекает из кода плеера объект разметки VideoObject, содержащий официальное название видео, длительность и ссылку на базовый .m3u8 манифест.
* Перехват Fetch и XHR запросов: Перехватывает сетевые запросы плеера в момент запуска видео или смены качества, вытягивая прямые ссылки на .mp4 файлы.
* Автоматическое разделение потоков: Самостоятельно определяет тип ссылки и сортирует их на видеопотоки (например, /1080p.mp4) и аудиопотоки (например, /audio_0.mp4).
* Умная очистка URL: Автоматически удаляет из ссылок все динамические параметры авторизации, подписи и токены (все, что идет после знака ?), оставляя ссылки в абсолютно чистом и постоянном виде.
* Поддержка динамических страниц (SPA): При переходе на другую лекцию или видео в рамках одной страницы расширение автоматически сбрасывает прошлые счетчики, удаляет старые элементы интерфейса и начинает сбор данных для нового видео с нуля.

## 💾 Как работает сохранение файлов

На главной странице сайта расширение выводит удобную плавающую кнопку:
💾  Save (m3u8 V: V1, m3u8 A: A1, mp4 V: V2, mp4 A: A2), где V1 — количество найденных видео плейлистов M3U8, A1 — аудио плейлистов M3U8, V2 — количество видеопотоков, A2 — аудиопотоков.
При нажатии на кнопку расширение автоматически генерирует и скачивает файлы в вашу стандартную папку Загрузки (Downloads) в подкаталог kinescope:

📂 Загрузки (Downloads)
 └── 📂 kinescope
      └── 📂 [Название_Вашего_Видео]
           ├── 📄 json-ld.json  <- Полные метаданные видео в формате JSON
           └── 📄 log.txt       <- Название, манифест, длительность и списки всех M3U8 и MP4 ссылок

Имя папки автоматически очищается от запрещенных операционной системой Windows символов (\ / : * ? " < > |).

## 🛠 Архитектура проекта

Проект использует гибридную схему обмена данными для обхода системной изоляции браузера Chromium и строгих политик Content Security Policy (CSP):

   1. manifest.json — объявляет права расширения (downloads, scripting) и форсирует внедрение во фреймы через match_origin_as_fallback.
   2. background.js — регистрирует сетевой шпион в контексте MAIN мира страницы и выступает «почтальоном» между вкладками.
   3. interceptor.js — работает в основном мире плеера, подменяет методы window.fetch и XMLHttpRequest, фильтрует ссылки по типу и передает их в изолированный мир через скрытый DOM-мост (document.documentElement).
   4. content.js — собирает данные внутри фрейма с помощью независимого таймера, передает их на главную страницу, управляет интерфейсом плавающей кнопки и формирует текстовые отчеты для скачивания.

## 🚀 Инструкция по установке

   1. Скачайте или скопируйте все 4 файла из каталога src проекта (manifest.json, background.js, interceptor.js, content.js) в одну локальную папку на компьютере (например, C:\Projects\kinescope-extractor).
   2. Откройте браузер (Google Chrome, Яндекс.Браузер, Edge или любой другой на базе Chromium).
   3. Перейдите по адресу: chrome://extensions/.
   4. В правом верхнем углу включите тумблер «Режим разработчика» (Developer mode).
   5. В левом верхнем углу нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).
   6. Выберите созданную вами папку с файлами.
   7. Перейдите на сайт с видео и обновите страницу (Ctrl + F5).

## 🐍 Автоматизация на Python (Пост-обработка)

После того как расширение сохранило файлы метаданных в папку `Загрузки/kinescope/[Название_Видео]`, для пакетной обработки используются два Python-скрипта.

### 1. Потоковое скачивание через FFmpeg (`download_all.py`)

Скрипт предназначен для циклического обхода всех подкаталогов в папке загрузок и автоматической сборки видео с помощью консольной утилиты FFmpeg.

**Принцип работы:** 
  1. Скрипт обращается к папке `Пользователь/Downloads/kinescope` и итерирует все вложенные директории лекций.
  2. Внутри каждой папки он ищет файл `log.txt`. Если в папке уже присутствует итоговый `.mp4` файл, скрипт пропускает её во избежание дублирования работы.
  3. Из файла `log.txt` с помощью поиска маркеров `"--- Video m3u8 ---"` и `"--- Audio m3u8 ---"` скрипт извлекает прямые ссылки на плейлисты видео- и аудиопотоков.
  4. Формирует и выполняет команду для `subprocess`, вызывая установленный в системе **FFmpeg** со списком разрешенных протоколов (`-protocol_whitelist file,http,https...`).
  5. FFmpeg на лету напрямую скачивает чанки видео и аудио, объединяет их без перекодирования (в режиме `-c copy`) и сохраняет готовый, полноценный медиафайл прямо в подпапку лекции под её оригинальным именем (`[Название_Папки].mp4`).

### 2. Сборщик готовых видео (`copy_mp4.py`)

Скрипт предназначен для финальной структуризации архива. Он автоматизирует извлечение готовых видеофайлов из глубокой структуры подпапок в единую общую директорию.

**Принцип работы:**
  1. Скрипт рекурсивно обходит (`os.walk`) дерево подкаталогов папки `Downloads/kinescope`.
  2. Находит все файлы с расширением `.mp4` (пропуская корень, чтобы не обрабатывать файлы циклично).
  3. Проверяет, нет ли файла с таким же именем в целевой папке назначения, чтобы не перезаписывать уже скопированные лекции.
  4. Использует метод `shutil.copy2()`, который переносит готовый `.mp4` файл в целевую папку, **полностью сохраняя оригинальные системные метаданные файла** (включая точную дату и время создания/изменения).
  5. В качестве аргумента принимает путь назначения. Если запустить скрипт без параметров (`python copy_mp4.py`), все видеофайлы будут извлечены и аккуратно сложены в текущую рабочую директорию, откуда был вызван скрипт.

## 🛠 Зависимости и предварительная настройка

Для корректной работы Python-скрипта download_all.py в системе должен быть установлен FFmpeg (утилита для конвертации и склейки медиапотоков). Скрипт вызывает её из командной строки для сборки сегментов видео и аудио из плейлистов .m3u8 в финальный файл .mp4.

### Установка FFmpeg

**На Windows:**

   1. Скачайте актуальную сборку (giggle/essentials) с официального сайта [ffmpeg.org](https://ffmpeg.org/download.html) или напрямую через пакетный менеджер Windows (Winget), выполнив в терминале:
   ```
   winget install Gyan.FFmpeg
   ```
   2. Если вы скачали архив вручную: распакуйте его в удобную папку (например, C:\ffmpeg) и добавьте путь к подпапке bin (например, C:\ffmpeg\bin) в системную переменную окружения PATH.
   3. Проверьте успешность установки, открыв новую командную строку (cmd) и выполнив команду:
   ```
   ffmpeg -version
   ```
   Вы должны увидеть техническую информацию о версии утилиты.

**На macOS / Linux:**

Установите утилиту через стандартные пакетные менеджеры:

   1. MacOS (Homebrew):
   ```
   brew install ffmpeg
   ```
   2. Ubuntu / Debian:
   ``` 
   sudo apt update && sudo apt install ffmpeg
   ```

### Зависимости Python

Для работы скриптов не требуется установка тяжелых сторонних библиотек. Все модули (os, shutil, subprocess, argparse, pathlib) являются встроенными в стандартную библиотеку Python. Достаточно иметь установленный Python версии 3.7 или выше.

## 💻 Полный Workflow автоматизации

1. Вы открываете страницу курса. Расширение перехватывает стримы. Вы нажимаете **`💾 Save`**. Браузер создает структуру `Downloads/kinescope/[Название_Лекции]/log.txt`.
2. По завершении сбора запускается скрипт **`python download_all.py`**. Он заставляет FFmpeg выкачать плейлисты из логов и собрать их в полноценные `.mp4` внутри своих папок.
3. Запускается скрипт **`python copy_mp4.py C:\Target\Archive`** (или просто без аргументов). Он достает все готовые видеофайлы из подпапок, сохраняет их оригинальные даты создания и собирает в одной удобной папке для просмотра, оставляя исходники нетронутыми.
